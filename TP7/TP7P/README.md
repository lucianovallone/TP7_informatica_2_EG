# INSTRUCCIONES PARA TP7 
## Requisitos
* Abrir el "TP7P.pde"
* Abrir el "TP7A.ino"
* Tener conectado vía USB un Arduino MEGA 2560 a su PC. (En caso de ser otro modelo checkear los pines)
* Conectar 2 pulsadores en D22 y D24. Conectar 2 Leds en D26 y D28

## Pasos
* Una vez conectado el Arduino, establecer la comunicación entre el mismo y Arduino IDE
* Posteriormente suba el programa a la placa
* Cuando se haya cargado, en processing ejecute el programa anteriormente mencionado

-Listo, ya podés usar y probar el programa!
